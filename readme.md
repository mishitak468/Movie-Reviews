# 🎬 Movie Review Platform API

A full-stack Python Flask API for a movie review platform where users can review movies and provide ratings.

## Features

- **Movie Management**: Create, read, update, and delete movies
- **Review System**: User reviews with 1-5 star ratings
- **Data Aggregation**: Calculate average ratings per movie
- **Duplicate Prevention**: Users can only review a movie once
- **Top-Rated Ranking**: Get movies sorted by average rating (stretch feature)
- **RESTful API**: Clean API endpoints with proper error handling
- **Unit Tests**: Comprehensive test coverage (23 tests passing)
- **Database Relationships**: Proper cascade deletes and constraints

## Technology Stack

- **Backend**: Flask, SQLAlchemy ORM
- **Database**: MySQL
- **Testing**: Pytest
- **Python Version**: 3.9+
